# Скрипты таблицы задач

Новая версия кода для Google Таблицы «Задачи». Колонки, их порядок и данные остаются прежними,
а все окна переделаны в одном стиле.

## Что изменилось

**Исправлено**
- «Поиск и правка» больше не может сохранить или удалить чужую задачу: скрипт ищет её по номеру, даже если
  строки сдвинулись.
- Нет лимита в 300 строк: поиск, отчёты, дашборд и письма видят все задачи.
- «Подрядчик» и «Менеджер» теперь красятся, и цвета у них разные.
- В дашборде SP по месяцам и годам считается правильно.
- При правке не теряются доп. ссылки.
- Кнопка «Скачать Excel» в отчёте по менеджеру работает.
- Два человека одновременно не получат один и тот же номер задачи.
- В журнал попадает и очистка поля. Вместо букв колонок пишутся названия полей.
- Ошибки в окнах показываются, а не пропадают молча.

**Удобство**
- Номер задачи: подрядчик-год-номер (`LIT-26-2232`), продолжает нумерацию старой таблицы.
- Цвета работают через правила. Поменяли статус руками — цвет поменялся сам. Добавили менеджера в «Списки» —
  появились и цвет, и пункт в выпадающем списке.
- Шапка одного цвета, закреплены «№ задачи», «Тикет» и «Тема», тема письма — жирным. Колонки «Смета, Итого»
  и «Статус отдачи, SP, Комментарий» собраны в группы: их можно свернуть кнопкой «–» над ними.
- Просроченные задачи подсвечиваются розовым, срок — красным.
- **Можно править прямо в листе.** Цвета обновляются сами, языки, вписанные руками, красятся. Новая задача,
  вписанная в пустую строку, получает выпадающие списки, а как только есть тема и подрядчик — номер.
  Кто и что менял — видно в «Файл → История версий».
- **Несколько ссылок на Band.** Основная — на теме письма, остальные — после темы: «(ссылка 2)», «(ссылка 3)»…, каждая
  кликается. В окнах и в расширении поле «Ещё ссылки на Band» сразу под основной: каждая ссылка с новой строки.
  Прежнее «(доп. ссылка)» читается как раньше и при правке переходит в новый вид.
- Колонка I называется «Срок сдачи»: это дата, к которой нужно сдать.
- Колонка R — **«Жалобы на заказчика»**, как в старой таблице. Есть в окнах «Новая задача», «Поиск и правка» и в расширении;
  при переносе истории жалобы попадают сюда. В старом листе колонка появится сама.
- В «Смете» вместо длинного адреса — короткая ссылка `Ссылка на смету LIT-26-2232`. Вставили адрес руками — он сам
  станет такой ссылкой. «Итого с НДС» — просто число, без «₽».
- Окно «Новая задача»: тема и «Скопировать» всегда видны наверху, языки — таблетками, редкие поля спрятаны,
  статус «Принято» по умолчанию, тикет можно вписать как `1234` или `LOCAL-1234`.
- Тема, которая заканчивается на «от», сама получает дату: `Перевод строчек Android и iOS от` → `… от 01.10`.
- **Шаблоны задач.** Заполнили форму → «Сохранить» рядом с «Шаблон» → дали название. В следующий раз выбрали
  шаблон — заполнились подрядчик, тикет, тема, продукт, ник, дедлайн, языки, а дата в теме («от 22.09») заменилась
  на сегодняшнюю. Шаблоны у каждого свои. «Скачать шаблоны» сохраняет их в файл, «Загрузить из файла» добавляет
  чужие: так можно поделиться с коллегой. Файл тот же, что у расширения.
- Коды языков в теме есть у всех языков, включая редкие (`he`, `tr`, `ko`, `ar`, `fr`, `be`). Код можно поменять
  или добавить новому языку в «Списках», колонка I «Код языка», в строке языка.
- **Проверка дублей**: если задача с той же ссылкой на Band или той же темой и тикетом уже есть, окно спросит,
  добавлять ли.
- **Перенос истории** из старой таблицы — см. ниже.
- «Поиск и правка»: одно поле поиска, пустой поиск показывает ваши задачи, статус меняется одной кнопкой.
- Дашборд: выбор периода, счётчик и список просроченных, деньги по подрядчикам.
- Префиксы подрядчиков (LIT, BP…) — в «Списках», колонка O. Новый подрядчик добавляется без правки кода.
- Разделы переводчиков берутся с листа «Справочник разделов».
- Инструкции переписаны как шпаргалки.

## Установка — проще всего: один файл

Всё (код, перенос истории, приёмник для расширения и все окна) собрано в **[`ВсёВОдном.gs`](ВсёВОдном.gs)**.

1. В таблице **«Расширения → Apps Script»**. Удалите все старые файлы (три точки у файла → «Удалить»).
2. «+» → «Скрипт», назовите `Всё`, вставьте текст `ВсёВОдном.gs` целиком, **Ctrl+S**.
3. Дальше — шаги 4–7 ниже (токен, развёртывание, «Оформить таблицу», перенос истории).
4. Один раз: слева «Сервисы» → «+» → **Google Sheets API** → «Добавить» (название оставить `Sheets`).
   Тогда «🙋 Мои задачи» и «Задачи одного менеджера» открываются в **личном представлении фильтра**:
   у каждого своё, другим в таблице не мешает, ссылку можно сохранить в закладки.
   Без этого сервиса работает обычный фильтр — но он общий: пока он включён, все в таблице видят только эти задачи.

Если хочется по отдельным файлам — ниже, но результат тот же.

## Установка по отдельным файлам

Всё делается в таблице: **Расширения → Apps Script**.

1. **`Код.gs`** — выделите весь старый код (Ctrl+A) и вставьте новый из [`Код.gs`](Код.gs).
2. **Окна (HTML)** — замените содержимое каждого файла на новое, названия файлов те же:
   `AddTaskDialog`, `SearchEditSidebar`, `DashboardSidebar`, `ManagerReportSidebar`, `CustomReportSidebar`,
   `AddTranslatorTaskDialog`, `SearchEditTranslatorSidebar`, `TranslatorReportSidebar`.
3. **Новые файлы**: «+» рядом с «Файлы».
   - HTML → `Общее` (без `.html`) — вставьте [`Общее.html`](Общее.html). Это общий стиль для всех окон.
   - HTML → `MigrateDialog` — вставьте [`MigrateDialog.html`](MigrateDialog.html). Окно переноса истории.
   - Скрипт → `Перенос` — вставьте [`Перенос.gs`](Перенос.gs). Нужен для переноса истории.
4. **`Smeta.gs`** — обязательно замените на новый из
   [`../smeta-extension/apps-script/Smeta.gs`](../smeta-extension/apps-script/Smeta.gs), иначе расширение
   не сможет добавлять задачи.
5. `TranslationStatus.gs` и `AddTranslationStatusDialog.html` больше не нужны — удалите их (три точки у файла → «Удалить»).
6. Сохраните (Ctrl+S). Затем **«Начать развёртывание» → «Управление развёртываниями» → ✏️ → Версия:
   «Новая версия» → «Начать развёртывание»**, чтобы расширение получило новый код.
7. Обновите таблицу (F5). В меню **«⚙️ Настройки» → «🎨 Оформить таблицу»**. Google попросит разрешение —
   разрешите. Пункт можно нажимать сколько угодно раз.

## Перенос истории из старой таблицы

«⚙️ Настройки → 📥 Перенести историю из старой таблицы». В окне два способа, любой:

- **Файл Excel** — проще всего. В старой таблице «Файл → Скачать → Microsoft Excel (.xlsx)», потом выберите
  или перетащите этот файл в окно. Доступ к старой таблице не нужен.
- **Ссылка** на старую таблицу. Тогда новая таблица её запомнит (см. ниже про номера).

«Проверить» покажет, сколько задач перенесётся (на ваших данных — 3811, с мая 2025), «Перенести» — перенесёт.
После переноса весь лист сортируется по дате: свежие сверху.

- Если одна задача подрядчику занимала в старой таблице несколько строк (объединённые ячейки), номер и тема
  копируются на каждую строку, а сумма сметы — только в первую, чтобы деньги не посчитались дважды.
- Номер тикета из колонки «Задача» (`LOCAL-493`) попадает в «Тикет», остальной текст — в «Комментарий».
- Если в ячейке «Тема в бенде» несколько ссылок: первая ставится на тему, остальные — «(ссылка 2)», «(ссылка 3)» после неё.
- «Сторона» переводится в «Продукт» по памятке («Портал продавца» → WBP, «Маркетплейс» → Магазинка и т. д.).
- Запускать повторно безопасно: то, что уже перенесено, пропускается. Так же можно подтянуть задачи,
  появившиеся в старой таблице после переноса.
- После переноса **по ссылке** новая таблица запоминает старую и при выдаче номера сверяется с ней: даже если какое-то время
  заводить задачи в обеих, номера не совпадут.
- Лучше перенести один раз и после этого не вести задачи в старой таблице, иначе номера разойдутся.
- Файлы `Перенос.gs` и `MigrateDialog` нужны только для этого; после переноса их можно удалить (тогда уберите и пункт меню
  «📥 Перенести историю» из `onOpen` в `Код.gs`).

## Чипы для языков (по желанию, одна минута)

Разноцветные «таблетки» в колонке «Языки», как в старой таблице, скрипт сам создать не может: их включают
вручную. Самый быстрый способ — перенести их из старой таблицы:

1. В старой таблице скопируйте любую заполненную ячейку «Языки» (Ctrl+C).
2. В новой выделите колонку G «Языки» со второй строки до конца.
3. Правый клик → **«Специальная вставка» → «Только проверка данных»**.

Если цвета не перенеслись: «Данные → Проверка данных» → правило колонки G → стиль «Чип», галочка
«Разрешить несколько вариантов», цвет для каждого языка.

Скрипт эти чипы не трогает, и новые задачи получают их автоматически.

## Проверка

После правки исходников сборку обновляет `node tools/bundle.js`.

Код проверен в Node на имитации таблицы с вашими данными (`test/run.js`, выгрузка таблицы — в `FIXTURE`): добавление, поиск, правка и удаление
при сдвинутых строках, отчёты, дашборд, письма, переводчики, запросы из расширения. Окна проверены в
браузере с подставными ответами. **В настоящей Google Таблице код не запускался** — если что-то
пойдёт не так, пришлите текст ошибки.
