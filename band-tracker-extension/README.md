# Band → Трекер

Расширение Chrome: задача в tracker.wb.ru из сообщения Band в два клика. Настраивать ничего не нужно,
токены не нужны: задача создаётся от вашего имени, как если бы вы нажали «Создать» в трекере.

## Установка

1. Распакуйте архив в папку, которую не будете удалять.
2. Откройте `chrome://extensions`, справа вверху включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное»** и выберите папку `band-tracker-extension`.
4. Закрепите иконку (🧩 → 📌). Обновите (F5) открытые вкладки Band.
5. Войдите в tracker.wb.ru в этом же браузере, если ещё не вошли.

## Как пользоваться

- В Band **правый клик по сообщению** → **«📮 Создать задачу в трекере»**. Откроется панель справа:
  название — первая строка сообщения, описание — текст и ссылка на сообщение с ником автора.
  Выделили часть текста перед кликом — возьмётся только она.
- Проверьте название, выберите тип задачи → **«Создать в трекере»**. Появится номер задачи со ссылкой,
  её можно скопировать.
- Без Band тоже можно: клик по иконке расширения → заполнить форму вручную.

## Типы задач

Адрес, куда трекер отправляет задачу, — это **пространство / проект / тип** (как справа в окне «Создание задачи»).
Встроен тип «Локализация» в проекте «Локализация» (Редакция). **Нужен другой тип или проект** (например, «Редактура»)?
Создайте одну задачу этого типа как обычно, прямо в tracker.wb.ru: расширение запомнит, куда трекер её отправил
(адрес, поля, названия «Проект» и «Тип»; без кук и паролей), и тип появится в списке «Тип задачи».
Поля берутся из этой задачи, поэтому создавайте её только с названием. Кнопка «▯▯» вверху — список: переименовать или убрать.

## Если не работает

- **«Не вижу входа в трекер»**: откройте tracker.wb.ru, войдите и попробуйте снова.
- **«Трекер не открылся»**: нужна рабочая сеть/VPN, трекер доступен только изнутри.
- **«Трекер не создал задачу …»**: пришлите текст ошибки тому, кто дал расширение.
- **Нет пункта в меню правого клика**: обновите вкладку Band (F5).

## Как устроено (для разработки)

- `band.js` — на band.wb.ru запоминает сообщение под правым кликом: текст в Markdown (ссылки под словами, жирный, списки), автора и ссылку `/<команда>/pl/<id>`.
- `background.js` — пункт меню, открывает панель, кладёт черновик в `chrome.storage`.
- `panel.*` — форма. Задача создаётся во вкладке tracker.wb.ru (`POST /api/gateway/catalog/…` с `x-csrf-token`
  из cookie `csrf_token`), потому что трекер пускает запросы только со своей страницы.
- `tracker-hook.js` + `tracker-bridge.js` — на tracker.wb.ru замечают, когда человек сам создаёт задачу,
  и запоминают тип задачи (адрес запроса, поля, названия из окна создания, пространство из адреса страницы).
